# الخصوصية والأذونات — مسودة تنفيذية

## المبدأ
التطبيق يعمل محليًا قدر الإمكان. لا يقرأ إشعارات تطبيقات النقل ولا يسجل الشاشة أو الصوت إلا بعد تفعيل المستخدم للميزة ومنح إذن النظام المطلوب.

## الأذونات
- **الإشعارات (Android):** مطلوبة فقط لوظيفة قراءة إشعارات الرحلات. يختار المستخدم تفعيلها من إعدادات Android، ويمكنه إيقافها في أي وقت.
- **الميكروفون:** مطلوب للتعرف الصوتي فقط. يجب إظهار حالة الاستماع بوضوح وإتاحة الإلغاء.
- **الكاميرا:** اختيارية لإدخال صورة يدويًا، ولا تعني السماح بالتقاط الشاشة.
- **مشاركة الشاشة (MediaProjection):** اختيارية، وتبدأ فقط بعد موافقة نافذة النظام. تنتهي الجلسة عند إيقاف المستخدم أو انتهاء صلاحية الإذن.
- **Accessibility:** ليست وسيلة افتراضية لالتقاط الرحلات. لا تُضاف إلا إذا ثبتت ضرورة تقنية محددة، مع شرح واضح وموافقة صريحة. لا تُستخدم للنقر أو قبول/رفض الرحلات.

## البيانات
- لا تُرسل الإشعارات أو الصور أو التسجيلات إلى خادم.
- لا تحفظ النص الخام أو الصور افتراضيًا بعد استخراج الحقول.
- اعرض للمستخدم البيانات المستخرجة ومصدرها ودرجة الثقة قبل اعتمادها.
- وفر حذفًا واضحًا للبيانات وسجل الرحلات والنسخ الاحتياطية.
- لا تجمع كلمات مرور أو رموز دخول تطبيقات النقل.

## حدود هذه الوثيقة
هذه مسودة متطلبات وليست إشعار خصوصية قانونيًا نهائيًا. يلزم مراجعة قانونية قبل النشر العام، وتوثيق كل SDK وأذونات Android الفعلية في النسخة النهائية.
