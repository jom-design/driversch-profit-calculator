# خارطة التنفيذ

## Phase 0 — Baseline and boundaries
- [x] توثيق خط الأساس المعتمد من main.
- [x] تحديد حدود الوحدات المستقلة ونقاط التكامل.
- [x] تسجيل غياب Android الأصلي والالتقاط الحقيقي واختبارات المشروع الآلية.
- [x] إنشاء فرع مستقل دون إدخال تاريخ PR #1.

## Phase 1 — Assistant domain foundation
- [x] عقود موحدة لمصدر الالتقاط وحقول الرحلة ودرجة الثقة.
- [x] تمييز Uber وDiDi وinDrive ومصدر غير معروف.
- [x] محلل مستقل للنصوص مع دليل لكل حقل وعدم افتراض القيم الناقصة.
- [x] اختبارات Node مخصصة لوحدة التحليل دون تعديل محرك الحسابات.
- [ ] إضافة عينات OCR منقحة ومجهولة الهوية لكل تطبيق.
- [ ] مراجعة قواعد كل تطبيق مقابل لقطات حقيقية وإصدارات مختلفة.

## Phase 2 — Inbox lifecycle
- [ ] حالات received / parsed / needs-review / confirmed / dismissed.
- [ ] منع إدخال الرحلة للحاسبة أو السجل قبل التأكيد.
- [ ] تخزين مؤقت مستقل مع سياسة احتفاظ وحذف واضحة.
- [ ] دمج واجهة صندوق الوارد دون تعديل الملفات المشتركة قبل مراجعة التكامل.

## Phase 3 — Web capabilities and voice
- [ ] فحص قدرات المتصفح الفعلية بدل إظهار أزرار غير مدعومة.
- [ ] إضافة SpeechRecognition عند توفره، مع حالة unsupported واضحة.
- [ ] أوامر صوتية محدودة داخل التطبيق؛ تأكيد قبل أي إجراء مالي أو حفظ.
- [ ] عدم الادعاء بأن صفحة الويب تستطيع قراءة إشعارات تطبيقات أخرى.

## Phase 4 — Android native
- [ ] إنشاء مشروع Android مستقل بعد حسم هيكل Gradle وSDK.
- [ ] NotificationListenerService بموافقة المستخدم وإعدادات واضحة.
- [ ] SpeechRecognizer وTextToSpeech الأصليان.
- [ ] MediaProjection اختياري مع موافقة النظام لكل جلسة.
- [ ] AccessibilityService غير افتراضي، ولا يُضاف إلا لضرورة مثبتة وموافقة صريحة.
- [ ] لا نقر أو قبول أو رفض تلقائي داخل تطبيقات النقل.

## Phase 5 — Persistence integration
- [ ] مراجعة تغييرات PR #1 أولًا وعدم نسخ حلول مؤقتة منه.
- [ ] تصميم ترحيل متوافق للإصدارات القديمة مع الاحتفاظ بالسجلات غير القابلة للتحقق.
- [ ] استيراد/تصدير ذري للرحلات والإعدادات.
- [ ] اختبارات ترقية قاعدة البيانات واستعادة النسخ الاحتياطية.

## Phase 6 — Quality and release readiness
- [ ] اختبارات وحدات وتكامل ومتصفح وPWA.
- [ ] اختبارات Android Emulator ثم أجهزة حقيقية.
- [ ] مصفوفة توافق أحجام الشاشات وإمكانية الوصول.
- [ ] دليل المستخدم والخصوصية والأذونات باللغة العربية.
- [ ] لا نشر Production دون تفويض مستقل.
